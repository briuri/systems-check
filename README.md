# Systems Check

This project contains my Systems Check solutions in Kotlin. 

The top-level of the project can be imported as an IntelliJ IDEA project. Solutions are found under 
`/src/` with a package naming convention of `buri.sc.y<yy>.q<qq>`. Each Quest can be run from a JUnit 
test harness, colocated in the day's `Puzzle` class.
